Build a Chrome Extension (Manifest V3) called "Applywise".

## PURPOSE
Single job: User uploads their resume PDF once. Gemini AI reads
it and extracts the complete profile automatically. When they 
open any job application page, AI scans all form fields and 
autofills everything. No login. No server. All data stored 
locally in chrome.storage.local.

---

## RESUME INPUT — TWO WAYS

### Primary: PDF Upload (Recommended)
- User uploads resume PDF in the popup
- Send PDF as base64 to Gemini API using inline_data
- Gemini extracts ALL fields automatically into a JSON profile
- No manual entry needed
- API endpoint:
  POST https://generativelanguage.googleapis.com/v1beta/models/gemini-flash-latest:generateContent
  Header: X-goog-api-key: API_KEY
  Body: { contents: [{ parts: [ { inline_data: { mime_type: "application/pdf", data: BASE64 } }, { text: EXTRACTION_PROMPT } ] }] }

### Secondary: Manual Entry (Fallback)
User can manually fill/edit any field after PDF extraction.
Fields are pre-populated from PDF, user just reviews and corrects.

## AUTOFILL ENGINE (Content Script)

When user clicks "⚡ Fill This Page":

1. SCAN: Collect all input, textarea, select on the page
2. Extract label for each field using ALL methods:
   - <label for="id">
   - aria-label attribute
   - placeholder attribute
   - name / id attribute
   - data-* attributes
   - Parent/sibling text nodes
   - Nearby <span> or <p> text
3. MATCH: Send field labels + profile JSON to Gemini API
4. Gemini returns JSON map: { fieldLabel: valueToFill }
5. FILL: Native value setter + dispatch input/change/keyup
   (works with React / Vue / Angular)
6. Cover letter fields: Gemini generates custom 150-word paragraph
7. Select dropdowns: match closest option text
8. Show floating toast: "✅ Filled X fields"

## Gemini Field Mapping Prompt:
"You are a job autofill assistant.
Form fields on this page: [LABELS_ARRAY]
Candidate profile: [PROFILE_JSON]
Job description (if found on page): [JD_TEXT]

Return ONLY a valid JSON object mapping each field label to
the correct profile value. Use null for no match.
For cover letter / about / message / why fields: write a
150-word tailored professional paragraph using the JD context.
No markdown. No explanation. Raw JSON only."

## GEMINI API INTEGRATION

Endpoint:
POST https://generativelanguage.googleapis.com/v1beta/models/gemini-flash-latest:generateContent
Headers: Content-Type: application/json, X-goog-api-key: {API_KEY}

Body for text:
{
  "contents": [{
    "parts": [{ "text": "YOUR_PROMPT" }]
  }]
}

Body for PDF:
{
  "contents": [{
    "parts": [
      { "inline_data": { "mime_type": "application/pdf", "data": "BASE64_PDF" } },
      { "text": "EXTRACTION_PROMPT" }
    ]
  }]
}

Parse response: data.candidates[0].content.parts[0].text
Strip markdown backticks before JSON.parse()
Always wrap in try/catch — fallback to rule-based matching.

## POPUP UI DESIGN

### Onboarding Screen (first launch)
Step 1: Enter Gemini API key
Step 2: Upload Resume PDF → "Extracting with Gemini..."
Step 3: Review extracted profile → "Looks good!"
→ Goes to main screen

### Main Screen (after setup)
- Resume filename + "Replace" button at top
- Profile preview: Name, Role, Company
- ONE big button: "⚡ Autofill This Page"
- Quick copy chips below: Email, Phone, Name, Skills, CTC
- Sidebar nav: Profile | Experience | Education | 
               Certifications | Projects | Settings

### Design
- Width: 360px
- Dark theme: #0c0e13 background
- Accent: #4fffb0 (mint green)
- Font: Bricolage Grotesque (display) + DM Mono (mono)
- Minimal — one purpose, zero clutter
- Sticky green fill button always visible
